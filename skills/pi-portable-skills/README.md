# Portable Pi skills

This local Pi package supplies eight reviewed skills from [`skills/`](skills/): `agent-browser`, `ddd-domain-discovery`, `ddd-strategic-modeling`, `domain-story-mapping`, `adr-decision`, `github-issues-projects`, `team-issue-workshop` and `commit`. Pi discovers them for **any** personality from this package. The personality extension then controls which discovered skills appear in the model prompt and in `/skills`.

The browser skill uses `agent-browser@0.42.0` via an exact npm dependency and committed lockfile; it does not download or copy the upstream skill instructions. After `node scripts/portable-pi.mjs update` from the checkout root, `npm ci` installs its CLI into this package. The wrapper [`scripts/browser.mjs`](scripts/browser.mjs) calls that exact installation without depending on a global PATH entry. Read the upstream `skills get core` guide through the wrapper before browsing; see [`skills/agent-browser/SKILL.md`](skills/agent-browser/SKILL.md). If Chromium is missing, run `node skills/pi-portable-skills/scripts/browser.mjs install` from the checkout. That browser download is not performed automatically by `update` because it is large and may need platform-specific setup. The executable smoke test checks the CLI version, not a launched browser.

The DDD skills are original operational guides informed by named experts; they are not copies of their books. `ddd-domain-discovery` collects evidence and asks focused questions, `ddd-strategic-modeling` records boundaries and invariants, and `domain-story-mapping` documents journeys and outcome-based increments. Albert Metzler's fixed child agent selects the original four; Waldemar's allowlist includes browser access, ADR coordination, the GitHub and `team-issue-workshop` workflows, and the `commit` skill, but not the DDD skills. [`adr-decision`](skills/adr-decision/SKILL.md) guides project-owned records under `.falkenwarte/knowledge/decisions/` for adopting projects without an existing convention; the domain skills place evidenced stories and models under `.falkenwarte/knowledge/domain/`. [`github-issues-projects`](skills/github-issues-projects/SKILL.md) scopes remote work and requires authorization before mutations. [`team-issue-workshop`](skills/team-issue-workshop/SKILL.md) leads a user-approved brainstorming session with relevant specialists, drafts an Issue and creates it through `gh` only after the user approves the exact repository and text; it then verifies and returns the Issue link. A local/global skill of the same name may take precedence in Pi discovery; resolve duplicates rather than assuming this package wins. To update the browser CLI, review the upstream release and its native binaries, change the exact version, regenerate `package-lock.json`, and rerun `update` and the smoke tests.
