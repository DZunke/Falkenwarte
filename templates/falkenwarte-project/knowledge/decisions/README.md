# Decisions

Use `NNNN-kebab-case.md` for each project ADR, starting at 0001. Mark a consequential proposal `Proposed` until the project's decision owner approves it; record evidence, alternatives, consequences, approver and verification. Keep accepted records and link a superseding ADR instead of rewriting the original rationale.

Index decisions here as they are created. The portable `adr-decision` skill contains an optional starting template.
