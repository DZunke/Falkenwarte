# Knowledge index

The project owns these Git-reviewed records; a running Pi session is not their source of truth.

- [`decisions/`](decisions/README.md) — numbered ADRs, evidence, alternatives, approval and verification.
- [`domain/`](domain/README.md) — domain stories and tentative or validated models with provenance.

Create only the material an actual assignment needs. Cite inspected paths or expert statements, keep contested terms visible, and never turn an assistant's suggestion into a fact or an accepted ADR. GitHub Issues and Projects can link the work, but do not replace decisions or domain evidence.
