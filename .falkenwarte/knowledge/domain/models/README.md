# Scoped domain models

One file models one agreed capability or bounded scope. Record the glossary with competing meanings, evidence paths, scenarios, candidate boundaries, invariants and unresolved decisions. A `Draft` model is useful; do not call it complete while the task depends on an unanswered expert question.

- [Portable agent and project knowledge](portable-agent.md) — a draft model grounded in this repository's current implementation.

Use [`_template.md`](_template.md) to start a different scope. A bounded context is a language/model boundary, not a package directory or a promise to create a service.
