# Domain stories

Record a real task scenario before extracting rules from it. Each note states actor, trigger, ordered actions/events, exceptions, outcome, sources and one unresolved question. Keep hypothetical examples clearly labeled and ask an expert before treating a proposed policy as fact.

- [Start a project assignment](start-project-assignment.md) — draft story of using this portable profile across repositories.

Use [`_template.md`](_template.md) for the next scenario. A story-map slice belongs here only when its user outcome and acceptance examples are clear.
