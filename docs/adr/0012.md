# ADR-0012: GitHub-Lieferkette und dokumentierte Entwicklung

**Status:** accepted.

**Datum:** 19. November 2026.

## Kontext

Falkenwarte wird über Pull Requests entwickelt. Die Lieferkette verbindet Änderungen, Dokumentation und Imageversionen nachvollziehbar.

## Entscheidung

Conventional-Commit-PR-Titel speisen Release Please. Das zu veröffentlichende Image wird an den geprüften Quellstand gebunden. Release- und QA-Workflows erhalten keine persönlichen Zugangsdaten für untrusted PR-Code.

Die besondere Auslösung der Prüfung für einen durch den Releasejob erzeugten Release-Pull-Request wurde später in [ADR-0015](0015.md) festgehalten.

## Konsequenzen

Produktdokumentation bleibt im Repository neben den Verträgen, damit Änderungen gemeinsam versioniert und geprüft werden können. Diese Entscheidung selbst berichtet keine einzelnen Workflowläufe oder Veröffentlichungen.

## Betrachtete Alternativen

Ein manuell gepflegtes Changelog und ein nicht an einen Quellstand gebundenes `latest`-Image hätten die Zuordnung zwischen Änderung und Artefakt erschwert. Ein externes Wiki hätte fachliche Änderungen und Code weiter voneinander getrennt.
