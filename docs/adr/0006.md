# ADR-0006: OpenAI Decisions über eine Symfony-AI-Erweiterung

**Status:** accepted für Konzeptfassung 2.0; Umsetzungs- und Abnahmenachweis siehe [Traceability](../TRACEABILITY.md).

**Datum:** 19. November 2026.

## Kontext

Nicht manuelle Eingänge müssen Themen und Workflowlabels erhalten. Der vom Nutzer ausgewählte Symfony-AI-PR #2956 ist zum Stand 19.11.2026 offen und nicht gemergt; eine vorhandene Beta1-Version beweist dessen native Fähigkeit nicht.

## Entscheidung

DecisionGateway wird durch SymfonyAiDecisionAdapter über PlatformInterface umgesetzt. Die native questions-basierte Decisions-Leitung ist das Ziel. Bis zu einem passenden Release ist eine schmale eigene Symfony-AI-Kompatibilitätserweiterung zulässig. Sie bleibt hinter eigenen fachlichen DTOs; M0 fixiert ein kohärentes installierbares Paketset.

## Konsequenzen

Der geprüfte PR-Head ist 581bfaae3fa9ab15b0d69f8308c6085f1c826ef6. NoulQuestion bildet auf den HTTP-Typ predicate ab. Eine belegte Refusal wird fachlich behandelt; eine unklare Konvertierungsexception liefert keine Freigabe. Nach einem nativen Release wird die Erweiterung gegen dieselben HTTP-E2E-Fixtures abgelöst.

## Betrachtete Alternativen

Ein Responses-Ersatz oder Jev ist nicht der gewünschte Vertrag. Ein beliebiges dev-main oder einzelne kopierte PR-Dateien würden Kompatibilität nicht sichern. Ein direkter Providerclient im Application-Code würde Symfony AI umgehen.
