# ADR-0010: Imagegebundene Plugins mit Laufzeit-Gates

**Status:** accepted.

**Datum:** 19. November 2026.

## Kontext

Plugins können Symfony-Dienste, MCP-Werkzeuge und UI-Beiträge bereitstellen. Ihre ausführbaren Dateien gehören zur Buildgrenze. Pluginzustände und historische Datensätze bleiben im lokalen Datenlebenszyklus erhalten.

## Entscheidung

Vertrauenswürdige Pluginpakete werden in das App-Image eingebaut. `PluginRegistry` liest ihre Manifeste und Capability-Verträge. `PluginAvailability` und `PluginLifecyclePolicy` schalten registrierte Beiträge zur Laufzeit.

## Konsequenzen

Aktivierung schaltet bereits vorhandene Beiträge ein, lädt aber keinen Code in den laufenden Prozess. Drain wartet auf offene Arbeit, und ein Entfernungsplan wird erst abgeschlossen, wenn das laufende Image das Paket nicht mehr registriert.

Pluginzustände und Übergänge stehen in `src/Extensions/Application/PluginHandler.php` und `src/Extensions/Domain/PluginLifecyclePolicy.php`. Pluginmanifeste registrieren die verwalteten Integrationsbeiträge.

## Betrachtete Alternativen

PHP- oder JavaScript-Code zur Laufzeit herunterzuladen hätte ausführbare Inhalte außerhalb des geprüften Images eingeführt. Ein eigener Container je Plugin hätte unnötige Laufzeit- und Betriebsabhängigkeit geschaffen.
