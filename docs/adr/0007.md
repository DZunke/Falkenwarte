# ADR-0007: Labels, Intake und menschliche Verantwortung

**Status:** accepted für Konzeptfassung 2.0; Umsetzung und Abnahme offen.  
**Datum:** 19. November 2026.

## Kontext

Tags müssen für Mensch und Agent dieselbe Bedeutung haben. Ein sichtbares Label allein kann weder eine offene Entscheidung speichern noch eine Zustimmung ersetzen.

## Entscheidung

Projektbezogene Labels haben stabile ID/Key, Namen, Farbe, Beschreibung und Art topic, workflow oder attention. Technische Eingänge erhalten einen dauerhaften Pflichtintake. Workflowlabels wählen versionierte Regeln. Menschlicher Handlungsbedarf wird aus offenen Eigentümergründen abgeleitet; eine Rückfrage an den Agenten bleibt gesondert sichtbar.

## Konsequenzen

Der Melder kann fehlende Angaben zum vorhandenen Ticket nachreichen. Origin wird serverseitig ermittelt. Manuelle Zuordnungen bleiben geschützt. Mehrdeutige oder unverfügbare Klassifikation startet keine Arbeit. Labeländerung allein erledigt keine Approval und ersetzt keinen aktiven Workflow.

## Betrachtete Alternativen

Freie vom Modell erfundene Tags würden die Taxonomie auflösen. Jedes Informationsdefizit sofort zum Menschen zu eskalieren würde die Agentenrückfrage wirkungslos machen. Eine rein kosmetische Human-Markierung wäre fachlich umgehbar.
