# ADR-0008: Link-Collections und klar zugeordnete Aussagen

**Status:** accepted für Konzeptfassung 2.0; Umsetzung und Abnahme offen.  
**Datum:** 19. November 2026.

## Kontext

Agents sollen Quell-Issues und Ergebnis-PR/MR melden können. Falkenwarte besitzt dabei keine Repository-/CI-Anbindung und darf aus einem Link keinen überprüften Status ableiten.

## Entscheidung

Tickets unterstützen geordnete benannte Link-Collections mit HTTP-/HTTPS-URLs, Titel, Beziehung und Herkunft. URLs werden syntaktisch geprüft und nicht serverseitig abgerufen. Berichte bleiben reported, können human_confirmed oder rejected werden und sind an den konkreten Ergebnisstand gebunden.

## Konsequenzen

Eine neue URL oder relevante Linkänderung verändert keine alte Bestätigung rückwirkend. Ergebnisbelege halten ihren Link-Snapshot; gegebenenfalls ist eine neue Bestätigung nötig. Es gibt keine Remotevorschau, Mergeaktion oder automatische Prüfung externer Tests.

## Betrachtete Alternativen

GitHub-/GitLab-/Jira-Connectoren überschreiten den aktuellen Scope. Automatisches URL-Unfurling würde ebenfalls eine neue externe Datenquelle schaffen. Ein unqualifiziertes verified würde eine nicht geleistete Prüfung suggerieren.
